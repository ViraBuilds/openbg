Why OpenBG?

remove.bg's standalone website and self-serve API shut down on 1 December 2026 at 09:00 CET. Background removal moved into Canva (Pro) and the API into Leonardo.Ai. OpenBG exists so anyone can keep doing background removal for free, with source, on their own machine.

It runs the BiRefNet-general ONNX model (MIT-licensed) on the ONNX Runtime via Rust. Drop a photo here and your local OpenBG server returns a full-resolution transparent PNG — nothing leaves this machine.

How does the web demo work?

This page talks to the local API server running on this machine (same origin, POST /v1.0/removebg). The image is sent only to your own OpenBG instance — there is no third-party upload. Run it yourself with cargo run --release -- serve --port 8080 and open http://localhost:8080/.

Honest limits

  • BiRefNet is very good, but slightly worse than remove.bg on fine hair, fur and translucent edges.
  • CPU inference takes a few seconds per image. A CUDA-capable GPU or Apple Silicon makes it dramatically faster.
  • The first run downloads the model (~224 MB by default) into your user cache directory.
  • The API is wire-compatible with remove.bg: existing code keeps working after changing only the URL.
